# Glyphix Deployment Checklist

Use this before deploying.

## Required
- [ ] `package.json` exists
- [ ] `app/` exists
- [ ] `components/` exists
- [ ] `lib/` exists
- [ ] project builds locally with `npm run build`

## Optional environment variables
- [ ] `GEMINI_API_KEY`
- [ ] `GEMINI_MODEL`
- [ ] `XAI_API_KEY`
- [ ] `XAI_MODEL`
- [ ] `OLLAMA_HOST`
- [ ] `OLLAMA_MODEL`

## Beginner-friendly path
- [ ] Upload repo to GitHub
- [ ] Import repo into Vercel
- [ ] Deploy with defaults
- [ ] Open live URL on Android
- [ ] Add API keys later
